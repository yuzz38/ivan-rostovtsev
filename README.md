# Лендинг: Иван Ростовцев — риелтор в Йошкар-Оле

Одностраничный сайт агента по недвижимости Ивана Ростовцева (Самолёт Плюс, Йошкар-Ола). Чистый HTML5 + CSS3 + Vanilla JS, без сборки и зависимостей — готов к публикации на любой хостинг.

## Структура

```
index.html            — страница (10 блоков) + JSON-LD (RealEstateAgent, Person, FAQPage, WebSite)
css/style.css         — стили, адаптив 320 px → 1920 px+
js/main.js            — меню-бургер, слайдер, табы, анимации, карта, форма
assets/img/           — фото в WebP + JPG (2–3 размера, srcset)
assets/video/         — фрагмент видео о менторстве у Дмитрия Малика (7,5 с, 0,5 МБ) + постер
assets/favicon.svg, apple-touch-icon.png, icon-192/512.png
robots.txt, sitemap.xml — SEO
llms.txt, llms-full.txt — GEO (для ChatGPT, Claude, Perplexity, Алисы, YandexGPT)
site.webmanifest, humans.txt
SEO.md                — семантическое ядро и чек-лист продвижения
```

## Блоки

1. Hero — «Продам вашу квартиру до 10 дней», цифры (100+ млн ₽, 35+ сделок, 25+ семей)
2. «Счастье любит тишину» — советчики зачёркиваются при прокрутке
3. Услуги — переключатель задачи: продать / купить / обменять / ипотека
4. Аукционный метод — шкала цены 7,5 → 8,1 → 8,35 млн, 17 покупателей
5. «Думаю на несколько ходов вперёд» — 4 шага работы
6. Результаты — три кубка 1 кв. 2026, видео о менторстве, сертификат
7. Истории клиентов — слайдер (свайп, стрелки, точки, клавиатура, drag мышью)
8. Обо мне
9. Вопросы-ответы (FAQ с разметкой schema.org)
10. Подарок (бесплатный разбор) + форма + карта сделок (12 адресов, Яндекс Карты)

## Перед публикацией

1. **Домен.** Везде стоит `https://rostovtsev-realty.ru/` — замените на реальный:
   `grep -rl "rostovtsev-realty.ru" . | xargs sed -i 's#rostovtsev-realty.ru#ВАШ-ДОМЕН.ru#g'`
2. **Отзывы.** В слайдере — реальные истории сделок со слов Ивана. Когда появятся отзывы клиентов (скриншоты с Авито, Яндекс Карт, ВК), добавьте их отдельными слайдами `<article class="story">` с именем автора.
3. **Подарок.** В профиле написано «Подарок 👇🏻» без расшифровки — на сайте это бесплатный разбор ситуации и оценка квартиры. Если подарок другой (чек-лист, гайд), поменяйте текст в блоке `#contact`.
4. **Форма.** Работает без сервера: собирает текст заявки, копирует его и открывает Telegram @Ivan_rostovtsev. Чтобы заявки падали автоматически, подключите бота Telegram или сервис форм (замените обработчик `submit` в `js/main.js`).
5. Добавьте сайт в Яндекс.Вебмастер и Google Search Console, отправьте `sitemap.xml`.

Совместимость: Safari iOS 12+, Chrome/Android 7+, Firefox, Edge, Яндекс Браузер, Samsung Internet. Учтены safe-area (вырез iPhone), `playsinline` для видео, отключение анимаций при `prefers-reduced-motion`.
